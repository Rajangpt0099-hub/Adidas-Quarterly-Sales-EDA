## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on Adidas quarterly sales data using Python.

The objective is to analyze historical quarterly revenue, identify important trends and patterns, study revenue growth, and generate meaningful business insights through data visualization.

The analysis uses **Pandas, NumPy, and Matplotlib** to clean, explore, analyze, and visualize the dataset.

---

## 🎯 Objectives

The main objectives of this project are:

* Understand the structure of the Adidas sales dataset.
* Perform basic data cleaning and validation.
* Analyze quarterly revenue trends.
* Identify the highest and lowest revenue periods.
* Study yearly revenue performance.
* Analyze quarterly/seasonal patterns.
* Calculate Quarter-over-Quarter (QoQ) growth.
* Identify periods of significant revenue growth and decline.
* Visualize revenue distribution.
* Generate meaningful business insights from historical sales data.

## 📂 Dataset

The dataset used in this project is:

### Dataset Features

| Column        | Description                                        |
| ------------- | -------------------------------------------------- |
| `Time Period` | Represents the year and quarter of the observation |
| `Revenue`     | Adidas quarterly revenue                           |

The dataset contains historical quarterly revenue observations that are analyzed to understand Adidas' sales performance over time.

## 🔍 EDA Process

The project follows a structured Exploratory Data Analysis workflow.

### 1. Data Loading

The dataset is imported using Pandas and inspected to understand its structure.

### 2. Data Understanding

The analysis checks:

* Number of rows and columns
* Column names
* Data types
* Missing values
* Duplicate records
* Statistical summary

### 3. Revenue Analysis

The project analyzes:

* Average revenue
* Median revenue
* Minimum revenue
* Maximum revenue
* Revenue range

### 4. Time-Based Analysis

The `Time Period` column is used to study:

* Yearly revenue
* Quarterly revenue
* Revenue trends over time
* Seasonal patterns

### 5. Growth Analysis

Quarter-over-Quarter revenue growth is calculated to identify:

* Revenue increases
* Revenue decreases
* Highest growth periods
* Largest decline periods

### 6. Visualization

Different charts are created to make the findings easier to understand.

## 📈 Visualizations

The project includes several visualizations, including:
